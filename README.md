📊 Sales Dashboard | 2023
A dynamic and interactive Sales Dashboard built to analyze business performance across multiple dimensions. This dashboard provides comparative insights between the Current Year (CY) and Previous Year (PY), with the flexibility to select any year as the baseline.

🚀 Features
Comparative Analysis

Automatically calculates PY metrics based on the selected CY.

Tracks growth percentages for Sales, Profit, and Quantity.

🛠️ Tech Stack
Data Source: Business transaction dataset (structured by order date, category, region, etc.)

Visualization Tool: Power BI / Tableau

Interactivity: Filters, slicers, and navigation buttons for seamless exploration

Design Elements: Line charts with min/max markers, bar charts for category comparisons, and weekly trend analysis

📌 Use Cases
Performance Tracking: Monitor year-over-year growth in sales, profit, and quantity.

Category Analysis: Identify top-performing and underperforming sub-categories.

Regional Insights: Compare performance across regions, states, and cities.

Trend Monitoring: Spot seasonal or weekly fluctuations in demand and profitability.

Customer Analysis: Drill down into customer-level dashboards for detailed buying behavior.

Decision Support: Provide actionable insights for sales strategy, inventory planning, and marketing focus.
